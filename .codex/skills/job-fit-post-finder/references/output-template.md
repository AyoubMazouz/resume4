# Output Template

## Active shortlist

For each job include:
- `Title - Company`
- `Link`
- `Post age`: exact age if shown; otherwise `Not shown (observed on <absolute date>)`
- `Location / Work mode / Contract`
- `Key requirements`: seniority, stack, language, hard constraints
- `Candidate-relevant details`: salary, process steps, on-call, relocation, assessment, email instructions
- `Fit`: Best fit / Good fit / Stretch
- `Why`: two short reasons
- `Risk`: one key gap

## Excluded as expired

Include only if needed:
- `Title - Company`
- `Link`
- `Status`: Expired
- `Evidence`: `This job has expired on Indeed`
